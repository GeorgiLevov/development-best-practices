# Learn in public for retention and accountability

**When to use**: When building mastery in a new domain over weeks or months.

**Rule**: Share concise artifacts of what you learned—short write-ups, working demos, or questions—in public or team channels. Teaching and summarizing reinforces memory and creates external momentum.

**Example**:
```text
Publish a 5-line TIL note with a minimal before/after snippet whenever a tricky CSS behavior finally clicks.
```

**Avoid**: Waiting until you feel like an expert before sharing notes or asking public questions.

**Source**: [Introduction — CSS for JavaScript Developers](https://courses.joshwcomeau.com/css-for-js/00-introduction/01-welcome)
