# Learn principles over memorizing recipes

**When to use**: When learning CSS or adopting a new UI technique.

**Rule**: Focus on understanding the underlying rules and algorithms (such as flow, inheritance, and unit scaling) rather than memorizing one-off recipes. Build an accurate mental model so you can solve unfamiliar layouts from intuition.

**Example**:
```text
Instead of memorizing: "Use flex + justify-content to center a card"
Ask: "Which layout mode owns this container, and how does it distribute free space?"
```

**Avoid**: Collecting social-media CSS tricks without understanding why they work or when they break.

**Source**: [Introduction — CSS for JavaScript Developers](https://courses.joshwcomeau.com/css-for-js/00-introduction/01-welcome), [The Surprising Truth About Pixels and Accessibility — Josh W. Comeau](https://www.joshwcomeau.com/css/surprising-truth-about-pixels-and-accessibility/)
