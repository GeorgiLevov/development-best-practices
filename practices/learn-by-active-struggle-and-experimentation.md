# Learn by active struggle and experimentation

**When to use**: When working through tutorials, docs, or unfamiliar APIs.

**Rule**: Do not consume technical material purely passively. Attempt exercises before checking solutions, or rebuild/tinker with working demos line by line so you form active mental connections.

**Example**:
```text
1. Read the problem requirements.
2. Write your own attempt in a live sandbox and observe what breaks.
3. Compare with the reference solution and test why differences matter.
```

**Avoid**: Reading solutions or watching walkthroughs end-to-end without writing or modifying code.

**Source**: [Introduction — CSS for JavaScript Developers](https://courses.joshwcomeau.com/css-for-js/00-introduction/01-welcome), [A World-Class Code Playground with Sandpack — Josh W. Comeau](https://www.joshwcomeau.com/react/next-level-playground/)
